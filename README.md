## 🗂️ Assignment Types

### 📊 Homework Assignments

These are mini-projects where we applied statistical concepts to analyze real-world or simulated data. Each homework is structured to answer a research question using multiple methods, often involving:

- Data wrangling & cleaning
- Applying statistical or predictive models
- Drawing interpretations from results
- Visualizing findings using ggplot2 or base R

### 💬 Discussion Submissions

These weekly submissions are more method-centric and conceptual. They involve:

- Writing or coding exercises to explain specific techniques
- Critical reflection on methods like skewness, Bayes theorem, or the Central Limit Theorem
- Smaller scale analyses demonstrating conceptual understanding
